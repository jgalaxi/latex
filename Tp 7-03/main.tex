\section{Corroboración de los datos con el software.}

Ya que en el trabajo final de grado no se especificaban todos los requerimientos de las piezas ni la composición exacta (o la más cercana), nosotros supusimos el peor de los casos para cada material, ya que la mayoría de las piezas repite materiales.

\subsection{Peor caso para cada material.}

Apoyandonos con Matweb, buscamos las propiedades mecánicas a mano de los aceros usados, ya que según el tratamiento térmico y las dimensiones con las que se los hizo cambian mínimamente dichas propiedades. A continuación, se detallan los peores casos que encontramos para cada material:

\subsubsection{Acero SAE/AISI 1010.}

\begin{itemize}
    \item AISI 1010 Steel, cold drawn bar, \SIrange[range-phrase={ - }, range-units=single]{19}{32}{\milli\metre} (\SIrange[range-phrase={ - }, range-units=single]{0,75}{1,25}{\text{in}}) round or thickness.
    \begin{itemize}
        \item $\sigma_{y} = \SI{305}{\mega\pascal}$.
        \item E $= \SI{200}{\giga\pascal}$.
        \item Dureza = 105 HB.
        \item Dureza = 108 HV (convertida desde HB).
        \item Costo= \SIrange[range-phrase={ - }, range-units=single]{0,75}{0,78}{\text{USD}\per\kilogram}.
        \item Densidad = \SI{7,87}{\gram\per\centi\metre\cubed} = \SI{7870}{\kilogram\per\cubic\metre}.
    \end{itemize}
\end{itemize}
